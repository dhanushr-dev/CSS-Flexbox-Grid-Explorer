Welcome

Introduction

Before diving in, understand what Flexbox and Grid are, why they exist, and when to reach for each.

↔️

What is Flexbox?

Flexbox (Flexible Box Layout) is a one-dimensional layout model designed for arranging items in a row or a column and distributing space dynamically. It excels at alignment, distributing space, and reordering elements along a single axis.

⊞

What is CSS Grid?

CSS Grid is a two-dimensional layout model that lets you control rows and columns simultaneously. It is ideal for page-level structure, complex grids, and overlapping content.

When should Flexbox be used?

  • Aligning items within a single row or column
  • Navigation bars and toolbars
  • Centering content vertically & horizontally
  • Components that need equal-height columns
  • Distributing space between elements dynamically

When should Grid be used?

  • Full page layouts with rows & columns
  • Magazine, gallery, and dashboard layouts
  • Designs that need precise two-axis control
  • Overlapping or layered content areas
  • Responsive grids without media queries

Flexbox Basics

The foundational concepts: turning an element into a flex container, and understanding the two axes that govern every flexbox layout.

display: flex

Definition: Turns an element into a flex container, making its direct children flex items that flow along a row by default.

Syntaxdisplay: flex | inline-flex;
Accepted values:
  • flex — block-level flex container
  • inline-flex — inline-level flex container
display: flex

display: inline-flex
1

3
(inline-level — notice how it doesn't take full width)
HTML 
<div class="container">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
CSS 
.container {
  display: flex;
}

Explanation: The moment you set display: flex, the container's main axis becomes horizontal (row) and its children lay out side-by-side instead of stacking.

💡 Tip: Use inline-flex when the container should only be as wide as its content, like a badge or button group.
Common use cases: nav bars, button groups, card rows, toolbars.

Main Axis & Cross Axis

Definition: Every flex container has a main axis (the direction items flow) and a cross axis (perpendicular to it). These two axes control how justify-content and align-items behave.

MAIN AXIS →
A
B
C
↓ CROSS AXIS

Explanation: justify-content aligns along the main axis; align-items aligns along the cross axis. Switch the axis by changing flex-direction and the two properties swap roles.

💡 Tip: If your alignment isn't doing what you expect, ask yourself: "which axis is the main axis?"

Flex Container vs Flex Items

Flex Container

  • The parent element with display: flex
  • Controls flow, alignment, wrapping & gaps
  • Properties: flex-direction, justify-content, align-items…

Flex Items

  • The direct children of the container
  • Controls their size, order & self-alignment
  • Properties: order, flex-grow, flex-shrink, align-self…

Section 3

Flex Item Properties

Properties applied to the children inside a flex container — controlling order, sizing, and individual alignment.

order

Definition: Changes the visual order of a flex item without changing the HTML source order.

Syntaxorder: <integer>; /* default 0 */
Item 2 has order: -1 (moves first)
1
2 (order:-1)
3
CSS
.item-2 { order: -1; }

Explanation: Lower numbers appear first. Items with the same order keep their source order.

⚠️ Tip: order changes visual order only — it does NOT change tab/reading order, so be careful for accessibility.

flex-grow

Definition: Defines how much a flex item should grow relative to its siblings to fill available space.

Syntaxflex-grow: <number>; /* default 0 */
grow 1 / 2 / 3 — proportional growth
grow:1
grow:2
grow:3
CSS
.item-a { flex-grow: 1; }
.item-b { flex-grow: 2; }
.item-c { flex-grow: 3; }

Explanation: A flex-grow of 2 doesn't mean "twice the size" — it means "absorb twice as much of the extra space".

flex-shrink

Definition: Controls how much a flex item shrinks when there isn't enough space. Opposite of flex-grow.

Syntaxflex-shrink: <number>; /* default 1 */
Middle item has flex-shrink: 0 (stays fixed)
shrink:1
shrink:0
shrink:1
CSS
.fixed-item { flex-shrink: 0; }
💡 Tip: Set flex-shrink: 0 on icons or avatars so they never get squished.

flex-basis

Definition: Sets the initial main-size of a flex item before free space is distributed.

Syntaxflex-basis: auto | <length> | <percentage>;
basis: 80 / 150 / auto
80px
150px
auto

.a { flex-basis: 80px; }
.b { flex-basis: 150px; }
.c { flex-basis: auto; }

Explanation: auto uses the item's content/width; a fixed value overrides that before growing/shrinking.

Grid Anatomy

Definition: A grid is made of lines, tracks, cells, and areas. Understanding these names is essential for using Grid properties.

Column Track
Row Track
Cell
Area (spans cells)
Line 1 Line 1

Grid Container

The element with display: grid. Defines tracks, gaps, and alignment.

Grid Items

Direct children. Each is placed into a cell or can span multiple cells.

Lines & Tracks

Lines are the dividing lines (numbered from 1). Tracks are the rows/columns between two lines.

Cells & Areas

A cell is a single row/column intersection. An area is one or more cells grouped together.

Section 9

Flexbox vs Grid

Both tools are powerful — here's how to choose between them, with the same layout built both ways.

↔️

Flexbox

One-dimensional

  • Best for: aligning items in a single direction
  • Advantage: dynamic space distribution
  • Advantage: perfect for components
  • Disadvantage: awkward for 2D layouts
  • Disadvantage: harder to align to specific columns
⊞

CSS Grid

Two-dimensional

  • Best for: full page & complex layouts
  • Advantage: control over rows and columns
  • Advantage: named areas for readability
  • Disadvantage: overkill for tiny components
  • Disadvantage: more verbose for single rows
