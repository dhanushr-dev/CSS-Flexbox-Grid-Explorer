# 📐 CSS Flexbox & Grid Explorer

A modern and interactive **CSS Flexbox & Grid Explorer** built using **HTML5 and CSS3**. This project demonstrates the fundamentals of CSS Flexbox and CSS Grid through practical examples, helping beginners understand responsive layouts and modern web design techniques.

## 🚀 Live Demo

🔗 https://css-flexbox-grid-exp.netlify.app/

## 📂 GitHub Repository

🔗 https://github.com/dhanushr-dev/CSS-Flexbox-Grid-Explorer

---

## 📌 Features

- 📦 CSS Flexbox Layout Examples
- 🧩 CSS Grid Layout Examples
- 📱 Responsive Web Design
- 🎯 Flex Direction & Flex Wrap
- ↔️ Justify Content & Align Items
- 📏 Gap Property Demonstration
- 🖼️ Grid Rows & Columns
- 📐 Grid Template Areas
- 🎨 Clean and Modern UI
- 💻 Beginner-Friendly Examples
